# Sistema de Gerenciamento de Biblioteca

Projeto desenvolvido para a disciplina de Projeto de Software.

## Tecnologias utilizadas

- Python
- Flask
- HTML
- MySQL

## Estrutura

O projeto utiliza arquitetura em três camadas:

- Front-end
- Back-end
- Banco de dados

## Objetivo

Desenvolver um sistema para gerenciamento de livros, usuários e empréstimos de uma biblioteca.
